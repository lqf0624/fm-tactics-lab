# 五大联赛与两轮测试 · v1114.6 验收

## 使用方式
1. 关闭旧版，打开同目录的 FM27-Tactics-Lab-1114.6.exe。
2. 进入「存档对战」，读取存档，选择联赛和测试球队。无需在游戏里执教该队。
3. 有保存战术可直接载入；其他球队选择「沿用当前战术 · 读取真实阵容」，再编辑战术或导入 FMF。
4. 「选择存档对手」可以筛选同联赛、五大联赛中的某一联赛或全部可用球队，支持跨联赛对战。
5. 开启「两轮测试」，底部填写第一轮每队场数，面板填写第二轮每队场数。需要比较时保存对照并勾选 A/B 对比。
6. 第一轮筛选，第二轮换不重叠种子复测，保持方案、对手和主客场一致。仅一套方案时为重复验证；双方针对性指令和指定盯人强制关闭。

## 数据与边界
原始.fm只读；读取缓存、比赛输入、两轮种子、日志和结果均保存在本地，并以存档文件身份隔离。EXE沿用既有用户数据目录，升级不会删旧实验。完整备份/恢复工具仍按 PRD 的后续计划开发。

AI对手采用明确标注的教练偏好预设，执教队可用保存战术；不声称恢复当天实际比赛。没有可靠战术或球员资料时给出原因。这个验收用于验证软件功能，100/120场的胜率不用于断言最强战术。
