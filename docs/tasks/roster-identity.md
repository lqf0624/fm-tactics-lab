## 试错与结论

| 现象 | 原因与处理 |
|---|---|
| 松木玖生曾显示为「玖生松木」 | 游戏词库的姓名片段在该球员上对应错位。按唯一 ID 和原名限定修正；通用姓名顺序使用稳定的国家／地区数据库编号 |
| 三名租借球员沿用旧比赛号码 | 读取时遗漏了接收俱乐部的有效租借注册。增加租借期限及球队校验；已明确未分配的号码保留为空 |
| 换档后阵容仍像上一赛季 | 球员显示缓存与战术板绑定分别按存档和俱乐部刷新，主客两边分别检查 |
| 升级后旧草稿的手工属性和首发被覆盖 | 旧版没有存档绑定，也没有新版迁移标记；不能据此认定需要自动重读。初始化保留未绑定的真实球员草稿，不写入会影响下次判断的标记 |
| 同构建的部分存档一线队战术和首发报布局错误 | 按结构识别扩展的战术计数尾部和定位球头部的计数记录；完整战术、无球映射和定位球分组仍通过既有校验 |
| 载入战术板时个别存档的替补身份为空 | 按已核实的存档 UID 和俱乐部筛选替补；无法核实的替补不进入比赛名单 |
