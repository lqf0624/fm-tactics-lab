# 阵容身份与球衣号码

对应 [A1、A2](../../PRD.md#6-验收标准)。进度：已在 v1114.2 的打包版验证，现行文档基线为 v1114.4。

## 进度与证据

- 两份曼联生涯档来回切换，芒特在 2027-02-06 为 7 号，在 2028-04-08 为 21 号。南安普顿的松木玖生显示为 27 号。新档曼联和南安普顿的 22 名首发都能读到当前注册号码。
- 当前注册号与同赛季曼联游戏导出文件的 67 个已编号记录逐一相符。游戏内完整姓名优先，词库缺项时可用原名；个别译名可由用户导出的名单补充。

## 试错与结论

| 现象 | 原因与处理 |
|---|---|
| 松木玖生曾显示为「玖生松木」 | 游戏词库的姓名片段在该球员上对应错位。按唯一 ID 和原名限定修正；通用姓名顺序使用稳定的国家／地区数据库编号 |
| 三名租借球员沿用旧比赛号码 | 读取时遗漏了接收俱乐部的有效租借注册。增加租借期限及球队校验；已明确未分配的号码保留为空 |
| 换档后阵容仍像上一赛季 | 球员显示缓存与战术板绑定分别按存档和俱乐部刷新，主客两边分别检查 |
