# 属性实验室

## 进度与证据

v1114 从战术板的「按位置选人」旁进入。默认选中战术板当前首发位置，按角色候选属性快速试跑。可选广泛筛选或在高级设置里改标准档位和推荐规则。固定和随机种子均支持，探索与复测共用各自独立的种子集。自由推演可用当前对手或客队战术池，存档模式可在实验配置中使用通用对手选择器，按同联赛、其他已加载联赛或全部可用球队选择对手。

曼联样例覆盖英超、西甲、法甲、德甲、意甲共 19 支对手。对一个首发位置的一项属性，每个对手完成 4 对探索和 2 对独立复测，共 228 场 Steam 原生比赛。界面回归从两个联赛一次提交了 39 支球队，普通存档对战的选队状态保持独立。自动回归 189 项通过，1 项因 Windows 符号链接权限跳过。

## 试错与结论

采用 PR #18 原有实验规则和报告，接到主版 Tauri 管道。报告从「实验结果」页导出为 HTML，同种子比较仅编辑目标球员的一项属性。角色候选是筛选范围，xG 差与每点收益依据该战术、球员和对手实测，不作为通用属性权重。
