# 属性实验室

## 进度与证据

v1114 从战术板的「按位置选人」旁进入。默认选中战术板当前首发位置，按角色候选属性快速试跑。可选广泛筛选或在高级设置里改标准档位和推荐规则。固定和随机种子均支持，探索与复测共用各自独立的种子集。自由推演可用当前对手或客队战术池，存档模式可用已选的 1–8 支存档对手。

## 代码入口

[比赛提交和续跑](../../src/fm27_tactics_server.py)、[配对与统计](../../src/desktop_attribute_analysis.py)、[弹窗与报告](../../src/tactics_ui/attribute-analysis.js)。

## 试错与结论

采用 PR #18 原有实验规则和报告，接到主版 Tauri 管道。报告从「实验结果」页导出为 HTML，同种子比较仅编辑目标球员的一项属性。角色候选是筛选范围，xG 差与每点收益依据该战术、球员和对手实测，不作为通用属性权重。

## 下次验证

覆盖更多球员位置、多个存档对手及验证阶段中断续跑。Epic 引擎完赛需在兼容 Epic 安装上复核。
